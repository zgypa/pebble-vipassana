# Pebble Vipassana

Pebble Vipassna is a Pebble Watchface for servers and students attending Vipasssana Courses as taught by S.N. Goenka.

The purpose of this watchface is to be able to use the Pebble Watch during a course, in such a way as to aid in the establishment of the technique by removing unnecessary time, and focussing on what is now, and what will come next.

## Features

- Shows battery status
- Show current day (not calendar day), days left: e.g. 2/-8 for a 10 day course.
- Show current session what to do: e.g. Rest/Anapana|Vipassana Group Sitting/Anapana|Vipassana Sit/Eat/Anapana Instruction/Vipassana Instructions
- Show Where to be now: Pagoda (with cell number), Dhamma Hall (with seat number), Room (with number), dining hall with number
- Show Where to be next, with countdown time hours:minutes
- Settings page on mobile phone (due to Pebble OS limitation)
  - date of next course start
  - date of next service period start
  - Room Number
  - type of course (10 day, Satipattana, 20 day, etc)
  - Pagoda Cell number
  - Dining Hall Number
  - Dhamma Hall cushion number
